## Maintenance

- Replace outdated information in `STATUS.md` after a coherent work unit; keep it short.
- Append implementation details and verification to the active progress log.
- When a log becomes cumbersome, close it, start the next numbered log, and update the progress index. Preserve closed logs.
- Update this guide and live navigation links when documents move. Historical paths in closed logs and mistake entries retain their original context.
- Paths to source code, data, and commands in documentation are relative to the repository root unless explicitly stated otherwise. Markdown navigation links are relative to their containing document.
- Detailed architecture and evaluation documents can contain older snapshots. Current status and relevant source inspection take precedence over historical numbers.
